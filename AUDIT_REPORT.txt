## Critical Bug Found & Fixed

**Issue:** `node:path`/`node:url` modules in `apps/web/src/generated/prisma/client.ts` were being loaded into Edge Runtime via `middleware.ts` → `auth-service.ts` → `db.ts` (Prisma client). Every request triggered `Ecmascript file had an error`.

**Fix:** Created `apps/web/src/lib/auth/middleware-auth.ts` — pure JWT verification (jose + env, no Prisma import) for use by middleware only. Updated `apps/web/src/middleware.ts` to import from `middleware-auth.ts`.

**Commit:** `7c4591e` — pushed to origin/main
