1. PROJECT OVERVIEW
══════════════════

ParmaConnect is a multi-tenant community management platform for
Indonesian residential communities (perumahan/kompleks). Built with
Next.js 16, Prisma 7, PostgreSQL, and TypeScript.

Stack:
  - Framework: Next.js 16 (App Router)
  - ORM: Prisma 7.9.0
  - Database: PostgreSQL
  - Language: TypeScript (strict)
  - Testing: Vitest 4.1.10
  - Linting: ESLint
  - Build: next build
  - Package Manager: pnpm
  - Node: v22

7. KEY ARCHITECTURAL DECISIONS
══════════════════════════════

  AD-001: Multi-tenant via communityId on all models
  AD-002: Role hierarchy: SUPER_ADMIN > ADMIN > DOCUMENT_ADMIN >
          FINANCE_ADMIN > SECURITY_OFFICER > STAFF > RESIDENT
  AD-003: AuditLog for all state changes
  AD-004: Prisma client generated to src/generated/prisma
  AD-005: Session-based auth (cookie), not JWT
  AD-006: Indonesian as default UI language
  AD-007: Centralized status transition validation
  AD-008: Announcement audience targeting (ALL/RESIDENTS/STAFF/
          SECURITY/FINANCE/ADMINS + block-level)
  AD-009: Report lifecycle: NEW→VERIFIED→ASSIGNED→IN_PROGRESS→
          RESOLVED→CLOSED (with REJECTED/DUPLICATE)
  AD-010: Internal notes filtered from resident timeline
  AD-011: Schema enhancement for InformationPage/GovernanceDocument
  AD-012: 9router (bban/deepseek-v4-flash) for delegation over Holver
  AD-013: Visitor codes via crypto.randomBytes (non-sequential)
  AD-014: Package status: ARRIVED→NOTIFIED→PICKED_UP (terminal)

8. KNOWN ISSUES
═══════════════

  1. Holver provider (api.holver-chat.web.id) not suitable for
     delegation — backend imposes output limit causing truncation
     even with max_output_tokens=65536 set.
  2. Package audit uses VEHICLE entity type (AuditEntityType missing
     PACKAGE enum value).
  3. Some UI list pages lack pagination for large datasets.
  4. 18 ESLint warnings (unused vars, minor style).
  5. .next/types/validator.ts not found error on fresh tsc (needs
     next build first — pre-existing, unrelated to code).
